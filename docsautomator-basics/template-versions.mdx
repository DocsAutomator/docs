DocsAutomator keeps a version of your Word template each time it changes. You can compare two versions, see which version made each document, and go back to an earlier version.

<Note>
  Template versions are available for [Word templates](/docsautomator-basics/word-template-guide). Google Doc templates keep their history in Google Docs.
</Note>

## When a new version is made

A new version is made when:

- you upload or replace the Word file;
- you save changes in the Word editor;
- you apply a template from the gallery or the library;
- the AI Agent creates or edits the template;
- you restore an earlier version.

If the new file is identical to the current one, no new version is made.

Saves in the Word editor do not make a new version for each small change. Saves by the same person within 30 minutes go into one version, as long as no document was made from that version yet.

## Open the version history

1. Open the automation.
2. In the template area, open the menu (three dots) next to **Edit Template**.
3. Click **Version history**.

The list shows each version with its number, its date, how it was made, who made it, and how many documents it generated and signed. The current version has a badge.

## Compare two versions

1. In the version history, select two versions.
2. Click **Compare**.

There are two views:

- **Visual** shows the pages of both versions side by side. The parts that changed are marked on each page.
- **Text** lists the lines that changed, were added or were removed. Lines that did not change are folded.

## See which version made a document

Each document records the template version that made it. Open the document on the **Documents** page to see the template version in its details.

For a signed document, the E-Sign Audit Trail and the signing certificate also show the template file, its version number and its SHA-256 hash. This shows exactly which template the signer saw.

## Restore an earlier version

1. In the version history, find the version you want.
2. Click **Restore** and confirm.

A restore does not delete anything. It makes a new version with the content of the earlier one, so you can always go back to the version you had before.

A version that was used for a document or a signature never changes. New edits always go into a new version.

## Download a version

Click **Download** next to a version to get its Word file.
