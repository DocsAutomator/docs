The **Documents** page (formerly called Run History) gives you access to a complete record of all document creation attempts within DocsAutomator. Open it from the **Documents** item in the left navigation, or go directly to [app.docsautomator.co/documents](https://app.docsautomator.co/documents).

<Note>
Old links to `/runhistory` redirect to `/documents` automatically.
</Note>

## What's Included

| Information | Description |
|-------------|-------------|
| Document Name | Name of the generated document |
| Automation | Which automation was used |
| Status | Success, failed, or in progress |
| Timestamp | When the document was generated |
| PDF URL | Link to the generated PDF |
| Error Details | Error messages for failed runs |

<Note>
Documents generated in Test Mode are excluded to keep the list focused on production documents.
</Note>

## Renaming Documents

To rename a generated document:

1. Click a document to select it. This works in list view and grid view.
2. Click **Rename** in the selection bar.
3. Type the new name and press Enter. Press Escape to cancel.

The new name is used in the document list, in search, in sorting, and as the file name in zip downloads. The original file in Google Drive keeps its generated name. Signature requests that are already out keep the name the signer first saw.

## Error Tracking

When runs encounter errors, the Documents page displays:
- The specific error message
- When the error occurred
- Which automation was affected

This information helps you diagnose and troubleshoot issues quickly.

## Accessing the Documents Page

1. Log in to DocsAutomator
2. Click **Documents** in the left navigation
3. Browse or search for specific documents
4. Click on any entry to see details
