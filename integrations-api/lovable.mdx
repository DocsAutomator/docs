Lovable uses DocsAutomator in two ways. The DocsAutomator connector lets Lovable create the template and the automation while it builds. A Supabase Edge Function calls the DocsAutomator API in the published app, because Lovable apps run their server code on Supabase. The [Supabase guide](/integrations-api/supabase) explains that function in detail.

## Add the DocsAutomator connector

1. In Lovable, open **Connectors**. Select **+** in the top right, then **MCP server**.
2. Enter `DocsAutomator` as the server name and `https://mcp.docsautomator.co/mcp` as the server URL.
3. Keep OAuth and click **Add & authorize**.
4. Sign in to DocsAutomator and choose a workspace.

Custom MCP servers work on every Lovable plan. The connector works in the Lovable chat only, not in the published app.

```text wrap
Build a quote app. A user enters their company name, the client's name, email and company, line items (item, quantity, unit price) and notes, then clicks "Send for acceptance". DocsAutomator turns it into a PDF quote and emails it to the client, who accepts it with one click.

First, set up DocsAutomator with the DocsAutomator connector:
1. Create an automation called "Quote acceptance".
2. Generate a Word template for a clean one-page quote. Use exactly these placeholders: company_name, quote_number, quote_date, valid_until, client_name, client_company, notes, total, and a line items table line_items_1 with the columns item, quantity, unit_price and amount.
3. Set how it completes to Acceptance. Signer 1's email is given with each request.
4. Set the automation status to test.
5. List the placeholders to confirm them, and tell me the automation ID.

Then build the app with Supabase:
- Ask me for my DocsAutomator API key. Store it as the secret DOCSAUTOMATOR_API_KEY, and the automation ID as DOCSAUTOMATOR_AUTOMATION_ID.
- Create an Edge Function "send-quote". It calls POST https://api.docsautomator.co/createDocument with the header "Authorization: Bearer DOCSAUTOMATOR_API_KEY" and the JSON body { automationId, data, recipients }. data holds the placeholders above, with line_items_1 as an array of { item, quantity, unit_price, amount }. The function computes each amount and the total. recipients is [{ signer: 1, email: client email, name: client name }].
- Never call the DocsAutomator API from the browser.
- After sending, show the returned pdfUrl and signingLinks[0].signingUrl.

Finally, ask me for my email address and send a test quote to it.
```

Lovable creates a **Quote acceptance** automation in test mode, builds the form and the Edge Function, and sends a test quote to you. The email has a **Review & Accept** button. Test documents have a watermark, and test acceptances are never billed.

## How it works

- The Edge Function sends the quote data and the client's email to `POST https://api.docsautomator.co/createDocument`.
- DocsAutomator fills the template, makes the PDF, and emails the client a link to accept.
- The response contains the PDF link and the acceptance link.

The API key stays in a Supabase secret. To send a quote automatically when a row is added, follow [Send a document when a row changes](/integrations-api/supabase#send-a-document-when-a-row-changes) in the Supabase guide. See [Create Document via API](/api-reference/documents/create-from-api) for all options.

## Go live

Open the automation in DocsAutomator and set its status in the top bar from **Test mode** to **Live**. Signing and acceptance are included in every paid plan. A signed or accepted document counts as one document in your plan.
