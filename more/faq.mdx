## Getting Started

<AccordionGroup>
  <Accordion title="What data sources does DocsAutomator support?">
    You can connect these data sources directly in an automation:

    - **Airtable**: OAuth connection with field mapping, linked tables, and nested line items
    - **Google Sheets**: automatic creation from new rows, manual trigger, and batch generation
    - **Google Forms**: a document for each new form response
    - **Notion**: OAuth connection with database mapping, page body as Markdown, and line items from Relations (including nested line items up to 3 levels)
    - **SmartSuite**: OAuth connection with solution and table mapping
    - **ClickUp**: OAuth connection with task automation

    You can also start document generation from these tools:

    - **Zapier**: the DocsAutomator app with its **Create Document** action
    - **Make**: the DocsAutomator app with its **Create Document** module
    - **n8n**: the DocsAutomator community node
    - **Glide**, **Noloco** and **Softr**: no-code integrations
    - **MCP**: connect an AI assistant such as Claude or ChatGPT to the [DocsAutomator MCP server](/integrations-api/docsautomator-mcp)
    - **API**: the [DocsAutomator API](/integrations-api/docsautomator-api) for any custom application

    In the app, the [DocsAutomator AI Agent](/features/docsautomator-ai-agent) can set up an automation for you from a plain-language description.
  </Accordion>

  <Accordion title="What output formats are available?">
    DocsAutomator always generates a **PDF**. For the PDF you can:

    - Save it in Google Drive, OneDrive or Dropbox
    - Attach it to an email (not while signing is on for the automation)
    - Write it back to your data source: an Airtable, Notion, SmartSuite or ClickUp file field, or its link in an Airtable or Notion field or a Google Sheets column
    - File it in a folder on your Documents page
    - Merge existing PDFs into it, or notify a webhook
    - Use the PDF URL returned in the API response

    With a **Word (.docx) template**, you can also keep the generated **Word file** with the **Save Word document** action. It is downloadable from the run history, and you can save it in Google Drive, OneDrive or Dropbox, or upload it to an Airtable, Notion or SmartSuite file field. You can attach the Word file to an email even if you do not keep it.

    With a **Google Doc template**, the **Save Google Doc** action saves an editable Google Doc in a Google Drive folder, and can write its link to your data source.

    See [Actions after Document Generation](/features/actions-after-document-generation) for every option.
  </Accordion>

  <Accordion title="How do I get started?">
    1. Create an account at [app.docsautomator.co](https://app.docsautomator.co) (sign up with Google, Microsoft, or email)
    2. Create a new automation and add a template: a Google Doc, a Word (.docx) file, or a PDF
    3. Open the **Data / Placeholders** panel and connect your data source
    4. Map your data fields to template placeholders
    5. Generate a preview to verify your document

    See the [Quickstart Guide](/docsautomator-basics/quickstart-guide) for a detailed walkthrough.
  </Accordion>

  <Accordion title="Is there a free plan?">
    No. Testing is free and unlimited, and you need no credit card to sign up. Test documents carry a watermark and do not count against a plan. To generate live documents without a watermark, you need a paid plan: Professional, Business or Scale. See [docsautomator.co/pricing](https://docsautomator.co/pricing).
  </Accordion>
</AccordionGroup>

## Templates

<AccordionGroup>
  <Accordion title="What template format does DocsAutomator use?">
    DocsAutomator supports three template formats:

    - **Google Docs**: pick a Google Doc from your Google Drive
    - **Word (.docx)**: upload a Word file
    - **PDF**: upload an existing PDF and place data fields on top of it in the visual editor

    In Google Docs and Word templates, you add placeholders with double curly brackets (`{{placeholder}}`). DocsAutomator replaces them with your data for each document. The [DocsAutomator AI Agent](/features/docsautomator-ai-agent) can also design a new Word template for you. See [Templates Overview](/docsautomator-basics/templates-overview) to choose a format.
  </Accordion>

  <Accordion title="Can I use existing Google Doc templates?">
    Yes. You can use any Google Doc as a template. Add placeholders (`{{fieldName}}`) where you want data inserted, then pick the Google Doc from your Google Drive when you add the template to the automation. You can also upload an existing Word file, or start from the [Template Gallery](https://docsautomator.co/templates/).
  </Accordion>

  <Accordion title="What placeholder syntax is supported?">
    DocsAutomator supports several placeholder types:

    | Type | Syntax | Example |
    |------|--------|---------|
    | Text | `{{fieldName}}` | `{{customer_name}}` |
    | Image | `{{image_fieldName}}` | `{{image_logo}}` |
    | Line items | `{{line_items_1}}` in a table row, then `{{field}}` in the cells | Invoice rows |
    | Conditional section | `{{section_NAME}}` ... `{{/section_NAME}}`, each tag in its own paragraph | Show or hide a section with rules you set in the section settings |
    | E-signature | `{{esign.type_signer}}` | `{{esign.signature_1}}` |

    See the [Placeholder Syntax Reference](/docsautomator-basics/placeholder-syntax-reference) for the full syntax.
  </Accordion>

  <Accordion title="Can the same placeholder appear multiple times in a template?">
    Yes. You can use the same placeholder in multiple places within a template. You only need to map the data once. DocsAutomator replaces all occurrences automatically.
  </Accordion>
</AccordionGroup>

## Pricing & Limits

<AccordionGroup>
  <Accordion title="What are the document generation limits per plan?">
    DocsAutomator offers three plans:

    | Plan | Documents per month | Automations | Billed monthly | Billed yearly (per month) |
    |------|---------------------|-------------|----------------|---------------------------|
    | Professional | 100 | 5 | $29 | $19 |
    | Business | 1,000 | 20 | $79 | $59 |
    | Scale | 5,000 | Unlimited | $199 | $149 |

    Every account can test without limits in **Test Mode**, with no credit card. Test documents carry a watermark and do not count against a plan. You need a paid plan to set an automation to **Active** and generate live documents.

    Existing customers on legacy plans (Starter, Professional, Business, Scale, 200, 500, 2000, 5000 and Unlimited) stay on their original pricing and document allowance for as long as they wish.

    Visit [docsautomator.co/pricing](https://docsautomator.co/pricing) for full details including overage rates and feature comparisons.
  </Accordion>

  <Accordion title="What happens when I exceed my document limit?">
    Overage documents are off by default. Turn on **Enable Overage Documents** in your workspace settings to keep generating documents above your plan's allowance, at a price per document:

    | Plan | Price per extra document | Overage cap (documents per month, plan included) |
    |------|--------------------------|--------------------------------------------------|
    | Professional | $0.20 | 250 |
    | Business | $0.10 | 2,000 |
    | Scale | $0.06 | 10,000 |

    You can change the setting once per billing period. If overage is off, or you reach the cap, the API returns a `402 Payment Required` error with the message "You have reached your documents limit. Please upgrade your plan" and a link to the subscription page.
  </Accordion>

  <Accordion title="What are the API rate limits?">
    | Scope | Limit |
    |-------|-------|
    | All API requests | 2,000 requests per 15 minutes per API key (requests to `GET /job/{jobId}` do not count) |
    | Test emails | 25 per hour per automation, 100 per hour per workspace, and at most 10 different recipients per hour per workspace |
    | Document generation | 5 documents generated at the same time per workspace; further requests wait in the queue |

    Exceeding a rate limit returns a `429 Too Many Requests` response.
  </Accordion>
</AccordionGroup>

## Data Sources

<AccordionGroup>
  <Accordion title="Which field types are supported for each data source?">
    DocsAutomator supports all standard field types from each data source, including text, numbers, dates, single/multi-select, attachments (for images), and linked records. Linked records in Airtable can be expanded into line items for table generation. For Google Sheets, each column maps to a placeholder.
  </Accordion>

  <Accordion title="Can I use multiple data sources in one automation?">
    Each automation is connected to a single data source. However, you can create multiple automations, one for each data source, and trigger them independently. If you need to combine data from multiple sources, you can use the [API](/integrations-api/docsautomator-api) or an integration tool like Zapier, Make, or n8n to aggregate data before sending it to DocsAutomator.
  </Accordion>

  <Accordion title="How does auto-creation work with Google Sheets?">
    When **Auto creation** is on, DocsAutomator checks your sheet every 5 minutes. It generates a document for each new row below the last row it processed, up to 50 rows per check. Use **Run now** to check at once. This is ideal for hands-off automation where documents should be created as soon as data is added. Google Forms automations check for new responses every minute.
  </Accordion>
</AccordionGroup>

## E-Signatures

<AccordionGroup>
  <Accordion title="What e-signature field types are supported?">
    DocsAutomator eSign supports four field types:

    | Type | Placeholder | Purpose |
    |------|-------------|---------|
    | Signature | `{{esign.signature_1}}` | Full signature capture (draw via mouse, trackpad, or touch) |
    | Date | `{{esign.date_1}}` | Date picker with auto-fill |
    | Text | `{{esign.text_1_name}}` | Text input (append `_name` for a unique label per field) |
    | Checkbox | `{{esign.checkbox_1_label}}` | Agreement checkbox (append `_label` for a unique name per field) |

    Increment the signer number for multiple signers (`_1`, `_2`, `_3`, etc.). There is no limit on the number of signers, and numbers need not be consecutive. See [Variable Number of Signers](/features/docsautomator-esign#variable-number-of-signers).
  </Accordion>

  <Accordion title="Is DocsAutomator eSign legally valid?">
    Yes. DocsAutomator eSign is compliant with the **ESIGN Act** and **UETA** in the United States, and **eIDAS (Simple Electronic Signatures)** in the European Union. Every signed document includes a Certificate of Completion with audit trail, SHA-256 document integrity hashing, and secure access tokens. See [Compliance & Legal Validity](/features/docsautomator-esign/compliance-and-legal-validity) for details. For documents that the recipient accepts instead of signs, see [Is acceptance legally binding?](/features/docsautomator-esign/is-acceptance-legally-binding).
  </Accordion>

  <Accordion title="What signing workflows are available?">
    Two signing workflows are supported:

    - **Parallel signing (default)**: all signers receive invitations at the same time and can sign in any order
    - **Sequential signing**: signers receive invitations one at a time in a defined order

    You set the signing order in the **Signing & Acceptance** panel of your automation.
  </Accordion>

  <Accordion title="How long are signing links valid?">
    Signing links expire after a configurable period, defaulting to **30 days**. You can set the expiration between 1 and 365 days. Two days before expiration, the sender gets an email warning. After expiration, links become invalid and the session status changes to "Expired."
  </Accordion>

  <Accordion title="Which plans include eSign?">
    Signing and acceptance work on every paid plan (Professional, Business and Scale), with no add-on subscription. In Test Mode you can try both with test documents. See [docsautomator.co/pricing](https://docsautomator.co/pricing) for the current price.

    In the **Signing & Acceptance** panel of an automation, choose under **How it completes**:

    - **Signature required**: the recipient fills the signature fields from your template and clicks Complete
    - **Acceptance**: the recipient reads the document and clicks Accept, with no signature fields (see [Acceptance](/features/docsautomator-esign/acceptance))
    - **No closing step**: the document is generated and delivered without signing or acceptance

    <Note>
    Legacy Unlimited-plan customers keep their included unlimited signatures until they change plans.
    </Note>
  </Accordion>
</AccordionGroup>

## Technical

<AccordionGroup>
  <Accordion title="What is async mode and when should I use it?">
    By default, the `POST /createDocument` endpoint runs synchronously and waits up to 5 minutes for the document to be generated. In **async mode** (send `"async": true` in the request body or `?async=true`), the API returns immediately with a `jobId` (HTTP 202) and you poll `GET /job/{jobId}` for the result.

    Use async mode when:
    - Your calling platform has execution time limits (e.g., Airtable's 120-second limit)
    - You are generating complex or large documents
    - You want non-blocking document generation in your application
  </Accordion>

  <Accordion title="How long does document generation take?">
    Most documents generate in **5-30 seconds**. Complex documents with many line items, images, or large templates may take longer. When using async mode, poll with exponential backoff starting at 2 seconds.
  </Accordion>

  <Accordion title="Can I override the template at request time?">
    Yes, for Google Doc templates. Pass a `docTemplateLink` parameter in your `createDocument` request with either a full Google Docs URL or a document ID. The override template must be accessible by your connected Google account. Automations with Word or PDF templates ignore this parameter.
  </Accordion>

  <Accordion title="Where are generated PDFs stored?">
    PDF and Word files are stored in our file storage (Cloudflare R2, EU). By default, they are kept until you delete them. You can set each automation to delete them automatically after about 5 minutes, 1 day, 3 days, 7 days, 14 days, 30 days, 3 months, 6 months or 1 year. For eSign-enabled automations, PDFs are automatically set to never expire. See [PDF Expiration / Storage](/features/pdf-expiration-storage) for details.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Why is my Google auth failing?">
    Google OAuth tokens can expire or become invalid. Common causes:

    - **Token expired**: Google refresh tokens may become invalid after extended inactivity. Reconnect your Google account in the DocsAutomator app under **Settings > Integrations > Google Permissions**.
    - **Insufficient permissions**: ensure the connected Google account has access to the template and destination folder.
    - **Shared Drive templates**: you need Manager (Organizer) level permissions on the Shared Drive. See [Google Shared Drive Permissions](/more/troubleshooting-guide/google-shared-drive-template-permissions).
  </Accordion>

  <Accordion title="Why are my images not showing in the generated document?">
    Images must be **publicly accessible** via URL. Common causes for missing images:

    - The image URL requires authentication or is behind a firewall
    - The URL has expired (e.g., temporary Airtable attachment URLs)
    - The image format is not supported (supported: JPG, PNG, GIF, WebP, SVG, TIFF, AVIF and HEIC; for a PDF, EPS or AI file, the first page is used)

    See [Dynamic Images](/features/dynamic-images) for details and best practices.
  </Accordion>

  <Accordion title="Why is my document generation slow?">
    Generation time depends on document complexity. Factors that increase generation time:

    - Large number of line items or nested line items
    - Multiple high-resolution images
    - Complex template with many placeholders
    - Google API rate limits during high-traffic periods

    If generation consistently exceeds expectations, enable [async mode](/api-reference/introduction#sync-vs-async-mode) to avoid timeouts.
  </Accordion>

  <Accordion title="Why is my placeholder not being replaced?">
    If a placeholder appears as raw text in the generated document:

    - Verify the placeholder name matches exactly (case-sensitive) between your template and data mapping
    - Check that curly brackets are not formatted differently (e.g., smart/curly quotes instead of straight brackets)
    - Re-type the placeholder directly in your template rather than copy-pasting, which can introduce hidden formatting
    - Ensure the data field is mapped and has a value in the source record
  </Accordion>
</AccordionGroup>
