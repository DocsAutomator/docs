## Problem

When generating documents via an Airtable automation script, requests that exceed 120 seconds fail with an error. This is an Airtable platform limitation on automation script execution time.

<Warning>
Airtable enforces a 120-second (2 minute) execution limit on all automation scripts. Complex documents may exceed this limit.
</Warning>

## Solution

Send `async: true` in the request. DocsAutomator then answers at once, and the script ends long before the limit. DocsAutomator keeps creating the document and saves the PDF to the record when it is ready.

The script in DocsAutomator already does this. Copy it again, or add one line to your own script.

<Steps>
  <Step title="Open the setup guide">
    In DocsAutomator, open your automation and click **Trigger from Airtable**. Pick the Airtable Automation script option, or the Airtable Interface button option.
  </Step>
  <Step title="Copy the script">
    Copy the script from the code box. It sends `async: true`.
  </Step>
  <Step title="Update Airtable">
    Paste the script into your Airtable automation in place of the old one.
  </Step>
</Steps>

If you keep your own script, add `async: true` to the body:

```javascript
body: JSON.stringify({
    recId: input.config().recId,
    docId: 'YOUR_AUTOMATION_ID',
    async: true
})
```

## How It Works

With `async: true`, the request returns right away with HTTP 202 and a `jobId`. The script does not wait for the document, so it does not need to check the job.

<Info>
The PDF link appears on the record, in the attachment field or the PDF URL field you set in your DocsAutomator automation. If no such field is set, find the document on the [Documents](https://app.docsautomator.co/documents) page. Errors show there too, because the script no longer sees them.
</Info>
